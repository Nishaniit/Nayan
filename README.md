## 🤖Robot Shooter🤖
**Robot Shooter** is a 3D shooting game where the player controls a robot and fights against enemy robots.

## Game Objective
The main objective is to **destroy enemy robots and achieve the highest possible score**.

## 🎮Controls
1. space: For moving
2. A: Rotate Counterclockwise
3. D: Rotate Clockwise
4. J: Small Bullet
5. K: Large Bullet
## ❤️Health System
* The player's health decreases when hit by enemy bullets.
* When health reaches **zero**, the game is over.

## ✨Features
* 2D robot shooting gameplay
* Enemy robots
* Shooting system
* Health system
* Score system
* Different types of bullets
* Background sound
* Pause menu

## 🛠️ Technologies Used
* Java
* 2D Models and Assets
* Sound Effects and Background Music

## 🚀 How to Run
1. Clone or download this repository.
2. Open the main scene.
4. Run the game.
